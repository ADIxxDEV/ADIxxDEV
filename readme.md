**Kopy Notes** is an open-source, offline-first teaching whiteboard for browsers, Windows and Android smartboards. No account, no subscription, no paid API needed.

- ✏️ Pressure pen, highlighter, laser, smart shapes, ruler, protractor & compass
- 📄 Import images, PDFs, DOCX, PPTX & ODP as slides
- 🎙️ Canvas recorder with optional mic and pause/resume
- 💾 Editable `.kopy` files, autosave, recovery copies & synced backup folders
- 🔒 Local-first: your lessons are never uploaded automatically

```bash
git clone https://github.com/ADIxxDEV/kopy-notes.git
cd kopy-notes
npm ci && npm run dev
```
